# 使用指南

面向已经装好或正在开发 Electron Lab 的人：侧栏每一页做什么、数据存在哪、出了问题怎么处理。

想从零跟一遍，先看 [上手教程](tutorial.md)。想按实验室模块对照 API，看 [实验室手册](lab.md)。

## 这是什么

Electron Lab 是日常桌面工具壳，外加一套可点的 Electron API 实验室。笔记、剪贴板、文件走主进程和 SQLite；页面只通过白名单 IPC 发命令，没有 Node、没有直接读盘。

仓库：<https://github.com/julytian/electron-lab>

## 安装与打开

1. 到 [Releases](https://github.com/julytian/electron-lab/releases) 下载对应平台的包。
2. **macOS（Apple Silicon）：** 打开 `electron-lab-*.dmg`。未签名时，若被拦，到「系统设置 → 隐私与安全性」允许打开。
3. **Linux ARM64：** 给 AppImage 加上执行权限后双击或在终端运行。
4. **x86_64 Linux：** 用该次 `master` 推送的 GitHub Actions 制品（Linux AppImage），或本机 `pnpm build:linux`。
5. 目前没有官方 Windows 安装包。需要的话本机执行 `pnpm build:win`。未签名包可能被 SmartScreen 拦。

开发态不要和正式包抢同一份用户数据：开发目录带 `-dev` 后缀。

## 界面

左侧是分组侧栏：工作台、窗口中心、浏览、实验室、设置。

- **命令面板：** `Command` + `K`（Windows / Linux 为 `Ctrl` + `K`），按标题跳页，也能打开最近文件。
- **最后停留的页面**会记住，下次启动回到那里。跨窗口通信的 `/ports/` 子页不记。
- 底栏显示平台、Electron 版本、更新状态和数据库是否就绪。

## 工作台

### 本地笔记

新建、搜索、置顶、删除。正文支持可选加密：打开加密后，库里存的是密文，密钥走系统 `safeStorage`（钥匙串 / 凭据）。

改过标题或正文会出现「未保存」。这时切到另一条、新建或离开本页，会问你「保存 / 丢弃 / 取消」。删除不走这三按钮，未保存时会提示将丢掉未保存改动。

关主窗或藏到托盘**不会**拦截未保存内容。

深链：`electron-lab://note/<id>`，例如 `electron-lab://note/12`。先在设置或「深链与文件关联」里注册协议。

### 剪贴板工作台

读、写系统剪贴板，并保留历史。点历史某一条会写回系统剪贴板，**不会**因此再插一行。可以删单条或清空历史。图片历史只显示文件名，不预览 HTML。

默认全局快捷键：`CommandOrControl+Shift+C` 打开本页。

### 文件与拖放

打开、保存、在文件夹中显示、丢进回收站、拖出文件。最近文件列表来自库，启动时会清掉已经不存在的路径。

超过 2MB 的文件不会读进正文，因此也不会标「未保存」。改过正文后再打开别的文件或离开本页，同样是「保存 / 丢弃 / 取消」。点工具栏「保存」不会先弹确认。

双击关联的 `.md`（安装包注册后）：读入最近文件；不超过 2MB 时会建成一条笔记。

### 截图与桌面捕获

列出屏幕和窗口源，选一个保存。页面不能自己调 `getDisplayMedia`，截屏只走这条 IPC。

### 下载中心

输入 https 地址开始下载。任务走迷你浏览器的 `persist:browser` 分区，不走主界面 Session。可暂停、继续、取消。

### 打印与 PDF

把当前主窗口内容导出为 PDF，路径由系统保存对话框决定。

### 系统能力

发系统通知（点击可回到本页）、读电源和空闲状态、看网络在线 / 离线、切换主题、开机自启。

在线状态来自主进程 `net.isOnline()`。进页或点「读电源」会刷新；电源变化和系统唤醒时也会推一次。不做断网轮询。

## 窗口中心

- **窗口实验室：** 由主进程创建子窗口或浮窗，可试进度条、全屏。
- **现代窗口外观：** 演示 `titleBarOverlay` 等，不是默认主壳。
- **跨窗口通信：** 左右两侧通过 MessagePort 传字。preload 只接受带 `MessagePort` 且来源可信的消息。

## 迷你浏览器

独立 Session（`persist:browser`），和主界面的 cookie、代理、拦截规则隔离。

地址栏支持 `https` 或简写主机名。工具栏：后退、前进、刷新。下一行是页内查找：输入关键字后「下一个 / 上一个」或回车，右侧显示 `n / m`。清空输入会停止查找并回到 `0 / 0`。

正式包不允许关闭证书校验。网络拦截、代理在「实验室 → 网络拦截与代理」里开关，只作用于这个分区。

## 设置

| 项                  | 说明                                                                                   |
| ------------------- | -------------------------------------------------------------------------------------- |
| 主题                | 跟随系统 / 浅色 / 深色                                                                 |
| 关闭到托盘          | Windows / Linux 有效。macOS 关窗即藏到 Dock，开关禁用                                  |
| 开机自启            | 当前平台不支持时会提示，不假装成功                                                     |
| 快捷键              | 格式如 `CommandOrControl+Shift+L`。默认：显示/隐藏窗口 `…+L`，剪贴板 `…+C`，笔记 `…+N` |
| 注册协议            | 把本应用设为 `electron-lab://` 的默认打开方式。开发态未安装包时可能不完整              |
| 自动检查 / 自动下载 | 只影响正式包。开发态更新走 mock                                                        |
| 导出数据库          | 复制业务库到你选的位置                                                                 |
| 清空业务表          | 删笔记、剪贴板历史、下载、最近文件、实验室日志；设置保留                               |

## 关于 / 诊断

查看更新五态、进度，打开日志目录，打开 GitHub 仓库。开发态或没有 `repository` 字段时，检查更新用 mock，页面会提示。

正式包启动约 10 秒后，若开启自动检查，会静默问 GitHub Releases。没有新版本或网络失败会 toast，不会退出。安装更新前若笔记未保存，会先确认。

## 数据在哪

主进程 SQLite + 键值设置（`electron-conf`）。库在应用 `userData` 下。

- 开发：`userData` 目录名带 `-dev`
- 正式包：普通 `userData`
- 日志：关于页「打开日志目录」，一般在 `userData/logs/`

不要用渲染进程拼绝对路径去读这些文件。

## 安全边界（使用时要知道的）

- 页面里 `require` 不存在；不能直接 `fs`。
- 迷你浏览器分区默认拒绝权限；主界面权限走白名单。
- 页面发起的屏幕共享（`getDisplayMedia`）会被拒绝，请用工作台截图页。
- HID / 串口 / USB / 蓝牙设备权限一律拒绝。
- 主窗渲染进程崩溃（非正常退出）最多自动 reload 两次；子窗和 GPU 只记日志，不重建。

对照表在「实验室 → 进程与安全」。

## 常见问题

**打不开 macOS 包？**
未签名。到「隐私与安全性」允许，或按系统提示「仍要打开」。

**开发态和安装包的笔记对不上？**
两套 `userData`。这是故意的。

**深链没反应？**
先注册协议。macOS 开发态可用：`open "electron-lab://note/1"`（先有 id 为 1 的笔记）。安装后再测 `.md` 文件关联。

**查找显示 `0 / 0`？**
没有匹配，或 2 秒内没等到结果。空关键字点「下一个」会提示关键字不能为空。

**清空数据后设置还在？**
清空只动业务表，主题、快捷键、协议登记等仍在。
